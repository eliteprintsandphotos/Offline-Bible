# Offline-Bible

## Reading it

Open `index.html` in any browser. It runs entirely from disk with no server and no
internet. Copy the whole folder (or just `index.html`, `reader/` and `data/kjv/kjv.js`)
to any device to take it with you.

- Pick a book and chapter, or use the ‹ › buttons (or ← → keys) to go between chapters.
- Type a reference like `John 3:16`, `1 Cor 13` or `Ps 23` in the box to jump there.
- Type any other words to search for that phrase; press `/` to focus the box.
- Tap a verse number to highlight it and get a link to it (e.g. `index.html#John.3.16`).
- A− / A+ change the text size and the half-circle button toggles dark mode. These
  settings and your place are remembered in this browser.
## Android app

Download the APK from the repository's **Releases** page (1.2 MB, Android 5.0 and newer).
It is the same reader with the whole Bible inside it. It asks for no permissions and never goes online.

**Installing it:** download the APK from Releases on the phone (or copy it over) and
open it. Android will ask you to allow installs from that app (Files, Chrome, etc.) the first
time. It isn't on Google Play, so Play Protect may also show a warning for an unknown developer.

In the app, the phone's Back button steps back through chapters you visited, then exits. The
app starts in light or dark to match the phone, and the status bar follows the reader's theme.

### Building the APK

`android/` holds the app source (`MainActivity.java` is a full-screen WebView over the reader).
When you build, the reader files from the repo root are copied in, so changes to `index.html`,
`reader/` or the Bible data are picked up automatically.

- **Command line, no Gradle:** `android/build-apk.sh` writes `android/build/OfflineBible.apk`.
  It needs a JDK plus either an Android SDK or, on Debian/Ubuntu,
  `apt-get install android-sdk-platform-23 android-sdk-build-tools apksigner zipalign dalvik-exchange`.
  Set `VERSION_CODE` / `VERSION_NAME` to bump the version.
- **Publishing a release:** push a tag such as `v1.1`
  (`git tag v1.1 && git push origin v1.1`). The *Android release* GitHub Actions workflow
  builds the APK and attaches it to a new release named after the tag.
- **Android Studio / Gradle:** open the `android/` folder, or run `./gradlew assembleRelease`
  in it.

Both builds sign with `android/debug.keystore` (password `android`), so either one can update an
installed copy. That key is committed on purpose and is fine for sideloading. To publish on
Google Play, make your own private key and change the app ID `com.offlinebible.reader`
(it's set in `android/app/build.gradle` and `android/build-apk.sh`) to one you own.

## Bible text

`data/kjv/` holds the complete King James Version (1769 standard text, public domain):
66 books, 1,189 chapters, 31,102 verses.

- `kjv.json`: the whole Bible in one file. `books[]` each have `id`, `abbrev`, `name`,
  `testament` (`OT`/`NT`) and `chapters`, which is an array of chapters, each an array
  of verse strings. So `books[b].chapters[c-1][v-1]` is chapter `c`, verse `v`.
- `kjv.js`: the same data as `kjv.json`, wrapped as `window.KJV = ...` so the reader can load
  it from `file://`, where browsers block `fetch()`.
- `kjv.tsv`: one verse per line (`book<TAB>chapter<TAB>verse<TAB>text`), useful for
  search indexes or loading into SQLite.

The files were generated by `scripts/build_kjv.py` from
[aruljohn/Bible-kjv](https://github.com/aruljohn/Bible-kjv). The verse counts were checked
against a second independent copy. Psalm titles and the Hebrew letter headings in Psalm 119
are not part of the verse text.
